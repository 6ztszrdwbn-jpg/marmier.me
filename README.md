# Site de cours de piano - Nathan

Site statique basé sur le template **Dimension** de HTML5 UP, personnalisé pour présenter les cours de piano de Nathan.

## Publier sur GitHub Pages

1. Uploader tout le contenu de ce dossier dans un dépôt GitHub.
2. Dans GitHub, ouvrir `Settings > Pages`.
3. Choisir la branche principale et le dossier racine.
4. Ouvrir l'URL GitHub Pages fournie par GitHub.

## Points a personnaliser

- Le lien Superprof se trouve dans `index.html`.
- Le formulaire est statique: il prépare un message à copier dans Superprof, sans serveur ni base de données.
- Le visuel principal est `images/piano-lesson-hero.jpg`.
